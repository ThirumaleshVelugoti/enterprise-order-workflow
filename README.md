# Enterprise Order & Workflow Management System
Enterprise-grade Order & Workflow Management System built using Java, Spring Boot microservices and React

## Overview
Enterprise-grade Order & Workflow Management System built using Java, Spring Boot 
microservices and React to demonstrate scalable, secure backend-heavy full stack design.

## Tech Stack
- Java 17
- Spring Boot, Spring Security
- Microservices Architecture
- REST APIs
- React
- PostgreSQL, MongoDB
- Docker

## Architecture (High-Level)
- Auth Service
- Order Service
- Workflow Service
- API Gateway

Project initialization in progress.
